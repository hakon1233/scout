## npm supply-chain attacks on React packages

- `2026-11-18` — Two npm packages with React-style names were flagged as malicious code that steals tokens.
  [socket.example — react-r2d2 flagged as malware](https://socket.example/blog/react-r2d2)
  > The npm package react-r2d2 was flagged as malicious after researchers found it sends npm tokens to a remote server on install.
  >
  > The package copied the README of a popular React hook library and had been downloaded about 1,200 times before npm removed it.
