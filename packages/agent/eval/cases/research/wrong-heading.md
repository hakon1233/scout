## Open-source AI agents

- `2026-10-02` — Northwind Labs released version 2 of its agent runtime.
  [northwind.example — Agent runtime 2.0](https://northwind.example/blog/runtime-2)
  > Northwind Labs shipped version 2 of its open-source agent runtime.
  >
  > Tool calls now run sandboxed by default, with 14 built-in tools moved over.
  >
  > Plugins that wrote to the home directory need changes; a migration guide exists.
  >
  > The old mode is removed in the November release.

## Also worth knowing

- `2026-09-29` — A shared format for agent run traces reached version 1.0.
  [examplefoundation.org — Trace format 1.0](https://examplefoundation.org/news/trace-format)
  > A working group published version 1.0 of a vendor-neutral agent trace format.
  >
  > Each model call, tool call and result is an event with a parent id.
  >
  > Four frameworks plan to emit it by year end.
  >
  > Evaluation tools are the first intended users.
